# @taffyjs/yoga Compatibility

The compatibility baseline is exactly `yoga-layout@3.2.1`. The package is permanently Node-only and ESM-only; it does not provide a browser or WASM backend.

Compatible means the supported API and its useful result match Yoga within the documented input boundary. Different means the API remains available but a named trigger returns stable Taffy geometry or deliberately corrected callback behavior. Unsupported means the package rejects a capability because it cannot provide credible semantics within the JavaScript-only compatibility layer.

## Calculation and computed output

The following calculation and output behavior is Compatible:

Compatible numeric comparisons allow an absolute error below `0.0001` for finite unrounded float fields, matching Yoga's own internal float-comparison tolerance. Rounded point-grid output and the exact fields covered by strict fixtures still compare exactly; this tolerance only covers last-bit differences when Yoga and Taffy evaluate equivalent percentage arithmetic in different float32 steps.

- `calculateLayout()` may select any live Node, including one still attached to a parent. Finite owner dimensions act as Yoga exact outer constraints when the selected Node has no definite declaration or maximum on that axis, without changing the declared Style.
- A successful calculation commits Yoga-shaped output for the complete selected subtree. `getComputedLayout()` and the six scalar layout getters preserve Yoga's left, right, top, bottom, width, and height semantics across LTR, RTL, reversed axes, relative positioning, and absolute positioning.
- `getComputedMargin()`, `getComputedPadding()`, and `getComputedBorder()` support Left, Top, Right, Bottom, Start, and End. Auto margins report zero, and Horizontal, Vertical, and All are rejected.
- Point-grid conversion follows each Node's own Config, including factor zero, mixed factors in one tree, and positive infinity. Computed edges other than left and top remain unrounded, as in Yoga.
- Ordinary fixed and percentage sizes, simple grow and shrink without min/max, and simple nested Flex trees match the pinned Yoga oracle. This is a bounded compatibility corpus, not a universal compatibility percentage.

## Known Differences

These rows are deliberate, version-specific differences with regression fixtures:

| Capability and trigger                                                                                            | `@taffyjs/yoga` behavior                                                                                                                                                                               | Yoga 3.2.1 behavior                                                                                                                     |
| ----------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------- |
| Change `useWebDefaults` on a live Config, then calculate a tree whose unresolved shrink values are already cached | Applies the current Config-sensitive Style when the selected calculation reaches Taffy. In the fixture, two 80-point children in a 100-point row become 50/50.                                         | The Config setter does not advance Yoga's cache version, so the same calculation retains 80/80 even though `getFlexShrink()` reports 1. |
| `setDirtiedFunc()` callback argument and `setDirtiedFunc(null)`                                                   | Calls a real callback with its canonical Node after state commit; null unsets the callback.                                                                                                            | Calls a real callback with zero arguments; null is retained and a later clean-to-dirty transition throws a wrapper TypeError.           |
| A max constraint combined with Flex shrink                                                                        | Keeps Taffy's Flex result. A width-120, max-width-90, shrink-1 child in a width-60 Row resolves to 60.                                                                                                 | The same child resolves to 67.5.                                                                                                        |
| Overlapping physical and logical main-axis margins under a child direction that differs from its parent           | Resolves the declarations to one physical Taffy margin rect. A width-20 RTL child with `margin-left: 4` and `margin-start: 10%` in a width-100 LTR Row remains width 20.                               | Computed margins are also left 4 and right 10, but Yoga's separate Flex margin resolution reduces the child width to 16.                |
| Calculated `aspectRatio`                                                                                          | Keeps Taffy's CSS-oriented aspect-ratio and stretch result. A width-40, ratio-2 child stretched by a 100-by-100 Row is 40-by-100.                                                                      | The same child is 40-by-20.                                                                                                             |
| `WebFlexBasis` disabled while a percentage basis is recalculated under a changed containing size                  | Recomputes the percentage basis. A 50% basis changes from 50 to 100 when its Row changes from width 100 to 200.                                                                                        | Reuses the stale 50-point basis while the experiment is disabled; enabling the experiment produces 100 in both implementations.         |
| Calculate an attached subtree with different owner dimensions, then calculate a clean ancestor                    | Restoring the selected Node's ordinary native Style invalidates Taffy's ancestor cache. The fixture returns the attached Row from width 100 to 200 and its children from 50 to 80.                     | The clean ancestor retains the attached-subtree result: Row width 100 and child width 50.                                               |
| Oversized `WrapReverse` lines with distribution-style `alignContent`                                              | Keeps Taffy's line placement. Three 60-point lines with heights 10, 20, and 15 in a 100-by-30 Row have tops 35, 15, and 0 under Stretch.                                                               | The same tops are 20, 0, and -15.                                                                                                       |
| A non-overflowing `WrapReverse` line with a cross-axis margin                                                     | Keeps Taffy's cross-axis margin placement. A 40-by-20 child with an 11-point bottom margin in a 100-by-100 Row has top 69 under `alignItems: FlexStart`.                                               | The same child has top 80.                                                                                                              |
| An oversized no-wrap reversed main axis with `SpaceBetween`, `SpaceAround`, or `SpaceEvenly`                      | Keeps Taffy's negative-free-space fallback. Widths 140, 130, and 120 in a width-240 `RowReverse` with `SpaceBetween` have left positions 250, 120, and 0.                                              | The same left positions are 100, -30, and -150.                                                                                         |
| A wrapped line whose stretched items resolve to zero cross size under distribution-style `alignContent`           | Keeps Taffy's line distribution. Two 60-point, flex-basis-zero children in a 100-by-180 Row with `alignContent: Center` both have top 90 for Wrap and WrapReverse.                                     | Both children have top 0 for Wrap and 180 for WrapReverse.                                                                              |
| Main-axis auto margins on a reversed axis or combined with a nonzero `justifyContent` offset                      | Keeps Taffy's distribution and masks computed auto margins to zero. A width-60 child with `margin-left: auto` in a width-240 `RowReverse` has left 360; the Center fixture has child tops 130 and 225. | Yoga places the reversed child at left 180; auto margins suppress the Center offset and produce tops 65 and 160.                        |

Measure callback modes, traces, and measurement-dependent results are completed and documented with the Measure milestone rather than being inferred from the non-measurement rows above.

The exhaustive Compatible, Different, and Unsupported API matrix will be finalized before this draft package is release-ready.
